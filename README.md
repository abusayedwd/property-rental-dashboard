# MyNextHome Admin Dashboard

React + Vite admin panel for **MyNextHome**. API: [property-rental-serverr](https://github.com/abusayedwd/property-rental-serverr) · Website: [property-rental-website](https://github.com/abusayedwd/property-rental-website)

**Features:** earnings overview with yearly chart, user and landlord management (detail view, block/unblock), all listings with hide/show and delete, reported-listing review queue, banners, contact info and static pages.

**Stack:** React 18 · Vite · Redux Toolkit / RTK Query · Ant Design · Tailwind CSS · Recharts

```bash
npm install
echo "VITE_BASE_URL=http://localhost:3070" > .env
npm run dev
```

Log in with an account whose role is `admin`.
